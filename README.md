# ✦ ASTRA — AI Assistant

Футуристический киберпанк-интерфейс AI-ассистента с двумя аватарами (ASTRA + Mia).

**Сделано так, как ChatGPT не смог.**

## Живая ссылка

После включения GitHub Pages ссылка будет:

### 👉 https://lexa25.github.io/ASTRA-AI-Assistant/

### Как включить за 30 секунд:

1. Открой репозиторий → **Settings**
2. Слева выбери **Pages**
3. Source → Branch: `main` → Folder: `/ (root)` → **Save**
4. Подожди 30–60 секунд и открывай ссылку выше

## Что есть

- Полноценный UI в стиле оригинального скрина
- Неоновые эффекты, стекло, городской фон
- Живые аватары с лёгкой анимацией
- Система готовности 100%
- Погода + живые часы
- Все инструменты
- **Реальное подключение к AI** (OpenRouter / Groq / OpenAI / xAI)
- Настройки API через шестерёнку ⚙️ (ключ хранится только в браузере)
- Адаптив под телефон

## Как пользоваться

1. Открой сайт (или `index.html`)
2. Нажми ⚙️
3. Выбери провайдера (рекомендую **OpenRouter**)
4. Вставь свой API-ключ
5. Сохрани и пиши сообщения
