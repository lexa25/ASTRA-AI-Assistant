# ✦ ASTRA — AI Assistant

Футуристический киберпанк-интерфейс AI-ассистента с двумя аватарами (ASTRA + Mia).

**Сделано так, как ChatGPT не смог.**

## Что есть

- Полноценный UI в стиле оригинального скрина
- Неоновые эффекты, стекло, городской фон
- Живые аватары с лёгкой анимацией
- Система готовности 100%
- Погода + живые часы
- Все инструменты (чат, код, генерация картинок, перевод, агенты и т.д.)
- Рабочее поле ввода + голосовая кнопка
- Нижняя навигация
- Адаптив под телефон

## Как открыть

1. Скачай репозиторий или открой `index.html`
2. Просто открой файл в браузере (Chrome / Safari / Edge)

Или через Live Server в VS Code.
