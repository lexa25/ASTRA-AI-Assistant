# ✦ ASTRA — AI Assistant

Футуристический интерфейс AI-ассистента в киберпанк-стиле с двумя аватарами.

## Возможности интерфейса

- **ASTRA** — главный ИИ
- **Mia** — контент-ассистент
- Чат, код, генерация изображений, перевод, погода и другие модули
- Красивый тёмный интерфейс с неоновыми акцентами
- Адаптивный дизайн

## Как запустить

Просто открой `index.html` в браузере.

Или через Live Server / любой локальный сервер.

## Структура

```
ASTRA-AI-Assistant/
├── index.html      # Основной интерфейс
├── styles.css      # Стили (cyberpunk)
├── script.js       # Интерактив
└── README.md
```
